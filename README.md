# 💼 JobSphere

A modern Job Portal built using React that allows recruiters to post jobs and candidates to apply seamlessly.

---

## 📌 Features

### Authentication

- User Login
- User Registration
- JWT Authentication

### Candidate

- Browse Jobs
- Search Jobs
- Filter Jobs
- Save Jobs
- Apply Jobs
- Update Profile

### Recruiter

- Recruiter Dashboard
- Post Job
- Edit Job
- Delete Job
- Manage Applications

### General

- Responsive Design
- React Router
- Context API
- Protected Routes

---

## 🛠 Tech Stack

- React

- REST API
- Axios
- React Router
- Context API
